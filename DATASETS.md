# DSN competition dataset
Source: https://www.kaggle.com/competitions/dsn-bootcamp-qualification-hackathon-2026-ml-track/data

Sign in to Kaggle and accept the competition rules to obtain train.csv, test.csv, and sample_submission.csv. Place all three beside the notebooks. These third-party competition CSVs are not redistributed by this repository.

Run python check_data.py to validate the original file checksums. The source manifest records the dataset files used for this snapshot. No test labels are included or invented.
